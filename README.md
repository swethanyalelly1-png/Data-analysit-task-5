# Data-analysit-task-5
Exploratory Data Analysis (EDA)

Task Description

This project performs basic Exploratory Data Analysis (EDA) using Python and Pandas. It analyzes student marks and displays useful statistical information.

Objectives

- Create a student dataset.
- Display the dataset.
- Calculate average marks.
- Find maximum and minimum marks.
- Check missing values.

Technologies Used

- Python
- Pandas
- Pydroid 3

Dataset

The dataset contains student names and their marks.

Student| Marks
Ravi| 75
Sita| 88
Ram| 60
Rani| 95
Kiran| 82

Analysis Performed

1. Displayed the student dataset.
2. Calculated average marks.
3. Identified maximum and minimum marks.
4. Checked missing values.
5. Displayed statistical information.

How to Run

1. Install Python and Pandas.
2. Copy the Python code into a file named "eda.py".
3. Run the program.
4. View the results in the output.

Expected Output

- Student dataset
- Data information
- Average marks
- Maximum marks
- Minimum marks
- Missing values

Conclusion

This project demonstrates basic EDA techniques using Python and Pandas without graphs. It helps understand and summarize data easily.
